===========================================================================
                 PRASM - РОДНОЙ АССЕМБЛЕР ДЛЯ x16-PRos
===========================================================================

ОБЗОР
-------------------------------------------
  PRASM - двухпроходный ассемблер, работающий прямо внутри x16-PRos.
  PRASM.BIN находится в BIN.DIR. Примеры исходников - в ASM.DIR.

ИСПОЛЬЗОВАНИЕ
-------------------------------------------
  prasm <исходник.asm>
    Собрать исходник.asm. Имя выходного файла получается заменой
    расширения исходника на .BIN.

  prasm <исходник.asm> <выход.bin>
    Собрать исходник.asm в файл с указанным именем.

СИНТАКСИС
-------------------------------------------
  Одна инструкция на строку.

  ";" начинает комментарий до конца строки.

  Метки заканчиваются на ":" и могут использоваться до того,
  как определены

  Мнемоники, имена регистров и метки нечувствительны к регистру
  букв. Длина метки - не более 15 символов.

  Числа:
    123            десятичное
    0x1F или 0X1F  шестнадцатеричное
    -5             отрицательное десятичное
    'A'            символьный литерал

  Строки (только в "db"):
    db "Hello, World!", 10, 13, 0

РЕГИСТРЫ
-------------------------------------------
  AX CX DX BX SP BP SI DI
  AL CL DL BL AH CH DH BH

ОПЕРАНДЫ В ПАМЯТИ (только MOV)
-------------------------------------------
  MOV - единственная инструкция, работающая с памятью.
  Поддерживаемые формы:

    mov ax, [label]      mov [label], ax
    mov al, [0x1234]     mov [0x1234], al
    mov ax, [bx]         mov [bx], ax
    mov ax, [si]         mov [si], ax
    mov ax, [di]         mov [di], ax

  Комбинированной адресации вида [bx+si] и смещений внутри
  скобок ([bx+4]) нет.

ДИРЕКТИВЫ
-------------------------------------------
  ORG <значение>
    Задать счётчик адреса для вычисления меток. Только число.
    По умолчанию 0x8000.

  ИМЯ EQU <значение>
    Определить именованную константу. <значение> - число,
    символьный литерал или уже определённая выше метка/EQU.
    Повторное определение имени - ошибка.

        WIDTH equ 40
        mov cx, WIDTH

  DB <элемент>, <элемент>, ...
    Выдать байты. Каждый элемент - число или строка в кавычках.

        db "Hello", 10, 0
        db 1, 2, 0x0A

  DW <элемент>, <элемент>, ...
    Выдать слова (16 бит, младший байт первым). Элемент - число
    или метка.

        dw start, 0x1234

  RESB <число>
    Выдать <число> нулевых байт. <число> должно быть уже
    известно (число или ранее определённая метка/EQU).

  TIMES <число> <инструкция>
    Повторить одну инструкцию <число> раз. Работает с любой
    инструкцией, включая DB с несколькими элементами. <число>
    должно быть уже известно.

        times 4 nop
        times 3 db 0xAA, 0x55
        times WIDTH db 0

ИНСТРУКЦИИ С ОПЕРАНДОМ
-------------------------------------------
  MOV  dst, src             reg,reg / reg,imm / reg,[mem] / [mem],reg
  ADD  dst, src             reg,reg / reg,imm
  OR   dst, src             reg,reg / reg,imm
  AND  dst, src             reg,reg / reg,imm
  SUB  dst, src             reg,reg / reg,imm
  XOR  dst, src             reg,reg / reg,imm
  CMP  dst, src             reg,reg / reg,imm
  TEST dst, src             reg,reg / reg,imm

  INC  reg                  8-битный или 16-битный регистр
  DEC  reg                  8-битный или 16-битный регистр
  PUSH reg16                только 16-битный регистр
  POP  reg16                только 16-битный регистр

  SHL  reg, imm/CL          сдвиг влево
  SHR  reg, imm/CL          сдвиг вправо (без знака)
  SAR  reg, imm/CL          сдвиг вправо (со знаком)

  MUL  reg                  умножение без знака, AL/AX x reg
  IMUL reg                  умножение со знаком, AL/AX x reg
  DIV  reg                  деление без знака, AX(:DX) / reg
  IDIV reg                  деление со знаком, AX(:DX) / reg

  INT  imm8                 программное прерывание

  JMP  label                безусловный ближний переход
  CALL label                ближний вызов

  LOOP  label               dec CX, переход если CX <> 0 (кор., +/-127)
  JCXZ  label               переход если CX = 0          (кор., +/-127)

  JO JNO JB/JC JAE/JNB/JNC
  JE/JZ JNE/JNZ JBE JA JS
  JNS JP JNP JL JGE JLE JG  условные переходы       (короткие, +/-127)

  REP   <строк. операция>   повторять пока CX <> 0
  REPE / REPZ  <строк. оп>  повторять пока CX <> 0 и ZF = 1
  REPNE / REPNZ <строк.оп>  повторять пока CX <> 0 и ZF = 0

  ORG   value               задать счётчик адреса
  ИМЯ EQU value             определить константу
  DB    item, ...           выдать байты / строки
  DW    item, ...           выдать слова
  RESB  count               выдать нулевые байты
  TIMES count <instr>       повторить инструкцию

ИНСТРУКЦИИ БЕЗ ОПЕРАНДА
-------------------------------------------
  NOP                       нет операции
  RET                       ближний возврат
  RETF                      дальний возврат
  IRET                      возврат из прерывания
  HLT                       остановить процессор

  CLD / STD                 сбросить / установить флаг направления
  CLI / STI                 сбросить / установить флаг прерываний
  CLC / STC                 сбросить / установить флаг переноса

  PUSHA / POPA              сохранить/восстановить все регистры
  CBW                       расширить знак AL в AH
  CWD                       расширить знак AX в DX:AX

  LODSB / LODSW             загрузить байт/слово из [SI], сдвинуть SI
  STOSB / STOSW             записать байт/слово в [DI], сдвинуть DI
  MOVSB / MOVSW             скопировать [SI] -> [DI], сдвинуть оба
  CMPSB / CMPSW             сравнить байты/слова по [SI] и [DI]
  SCASB / SCASW             сравнить AL/AX с байтом/словом по [DI]

СООБЩЕНИЯ ОБ ОШИБКАХ
-------------------------------------------
  Каждая ошибка выводится как "Error, line N: <сообщение>":

  Syntax error              строка не разбирается
  Bad character             встречен неожиданный символ
  Bad number                некорректное дес./шестн. число
  Bad string                незакрытая строка в кавычках
  Name too long             имя длиннее 15 символов
  Unknown instruction       мнемоника не распознана
  Duplicate label           метка или EQU определены дважды
  Too many labels           более 220 меток/констант
  Undefined label           метка использована до определения
  Operand size mismatch     смешаны 8-битный и 16-битный операнды
  Bad memory operand        неподдерживаемая форма [ ... ]
  Jump out of range         короткий переход дальше чем +/-127
  Output too big            результат превышает предел размера

ОГРАНИЧЕНИЯ
-------------------------------------------
  Исходный файл             до 15872 байт
  Меток + EQU               до 220 записей
  Выходной файл             примерно до 23 КиБ
