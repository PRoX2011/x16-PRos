===========================================================================
                                 Doom8088
===========================================================================

The Doom8088 is a port of Doom to Intel 8088 written 
by Frenkel Smeijers (FrenkelS).

  Source code:  https://github.com/FrenkelS/Doom8088
  License:      GNU GPL v2

x16-PRos only ships the binary here; nothing in the game was changed.
Grab the code from the link above.

---------------------------------------------------------------------------
What is in this directory
---------------------------------------------------------------------------

  D8088MYH.EXE   Doom8088, build v20260304
  DOOM1.WAD      Doom 1 shareware data from id Software (episode 1 only)

---------------------------------------------------------------------------
Running it
---------------------------------------------------------------------------
  Just type "D8088MYH.EXE" in the terminal

Sound effects come out of the PC speaker. There is no music, no saving and
no multiplayer - that is the 8088 port, not x16-PRos bugs.

---------------------------------------------------------------------------
Controls
---------------------------------------------------------------------------

  Arrow keys ....... walk
  Ctrl ............. fire
  Enter / Space .... use
  Shift ............ sprint
  Alt .............. strafe
  [ and ] .......... change weapon
  Tab .............. automap
  Esc .............. menu
  F10 .............. quit
